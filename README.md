🤖 Mah Buddy
![Mah Buddy Preview](./mah-buddy-preview.png)
Your AI-powered learning companion.

Mah Buddy is an AI-powered learning and conversational application built to make studying, asking questions, and practising knowledge more interactive and personalized.

«Built by "ZEDRO Corp" (https://github.com/Zed-ro-bee).»

---

🌟 What is Mah Buddy?

Mah Buddy is designed to be more than a basic chatbot.

It combines AI-powered conversations with learning-focused tools to help users understand topics, practise what they've learned, and study at their own pace.

Whether you're asking a question, practising with a quiz, or reviewing flashcards, Mah Buddy is designed to make the learning experience more engaging.

---

✨ Features

💬 AI Conversations

Ask questions and have natural conversations with Mah Buddy.

📚 Personalized Learning

Learning experiences can adapt to the user's selected learning level and difficulty.

🧠 Quizzes

Practise your knowledge with dynamically generated questions.

🃏 Flashcards

Review concepts using interactive flashcards.

🎯 Learning Preferences

Mah Buddy can use information such as learning level, studies, goals, and selected difficulty to provide a more personalized experience.

🔊 Voice Features

Voice functionality allows users to interact with and listen to responses where supported.

👤 Accounts & Personalization

User accounts allow application preferences and relevant learning information to be associated with the user's experience.

🚀 Getting Started

To run Mah Buddy locally, clone the repository:

git clone https://github.com/Zed-ro-bee/mah-buddy-1.git

Move into the project:

cd mah-buddy-1

Install dependencies:

npm install

Create your environment configuration and add the required API and service credentials.

Then start the development server:

npm run dev

Open the local development address provided by Next.js in your browser.

---

🔐 Environment Variables

Mah Buddy may require environment variables for services such as authentication, databases, and AI functionality.

Never commit private API keys, passwords, service-role keys, or other secrets to this repository.

Use a local ".env.local" file for development and configure production secrets through your hosting provider.
