# Mah Buddy — Design Lock

Status: **LOCKED**

The current Mah Buddy visual design is now the approved baseline and must not be redesigned, replaced, or restyled without an explicit instruction from the owner to unlock or change the design.

## Locked scope

This lock covers **all visual/UI design**, including:

- Intro / splash screen
- Get Started and authentication screens
- Chat interface and message composer
- Header, navigation, buttons, icons and controls
- Profile and settings screens
- Light/dark theme presentation and visual contrast
- Study, flashcard and quiz screens
- Difficulty/level presentation
- Cards, modals, sheets, forms, inputs and switches
- Typography, spacing, sizing, borders, shadows, radii and animations
- Brand colors, logo/wordmark treatment and visual assets
- Responsive/mobile/desktop layouts
- App-like visual behavior and overall visual hierarchy

## Change rule

Future work should be **functional only** unless the owner explicitly asks to change the design. Bug fixes may correct broken visual behavior while preserving the approved design language.

An explicit owner instruction such as **"unlock the design"**, **"change the design"**, or a specific requested design change is required before redesign work begins.

This file is the source-of-truth declaration for the design freeze.
